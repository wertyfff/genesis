Memory

What Genesis remembers, on rules you set.

All productsJoin the waitlistJoin the waitlist→
Overview

Memory holds your files, preferences and past decisions, organised by project. You can see every item, correct it or delete it, and nothing crosses between projects without your say.

Visible

Every remembered item is listed in plain language, with where it came from.

Scoped

Memory belongs to a project. A client project never leaks into a personal one.

Erasable

Delete one item, a whole project, or switch memory off. Deletion is permanent.

Details
  • DefaultOn, per project
  • ControlsView, edit, delete, switch off
  • TrainingNever used to train models
  • ExportAny time, in open formats
